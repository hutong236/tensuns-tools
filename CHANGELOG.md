# Changelog

## 4.2.1
- Editable Web login URL and username without startup flags; persist only authenticated new profiles without rebinding existing history.
- Separate single-instance, batch import and sync modes; reset preview, confirmation and result on navigation.
- Add API and Chromium regression tests.

## 4.2.0
- Persistent full or scoped snapshots, JSON download and history.
- Field-level diff across snapshot/current catalog or two snapshots, including cross-service ID conflicts.
- Add-only cross-environment sync from saved snapshots, explicit preview, confirmation and report provenance.
- CLI diff and additional mock tests.

## 4.1.0
- Multiple connection profiles, no stored passwords.
- XLSX import/export and template in Web; five formats in CLI.
- Per-profile persistent reports, task status and live progress.

## 4.0.0
- Embedded local Web console with CLI shared core.
